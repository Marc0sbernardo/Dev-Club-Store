# 🛒 DevClub Store

Uma landing page de vitrine de produtos com design futurista e dark mode, desenvolvida com HTML, CSS e JavaScript puro.

---

## ✨ Demonstração

A página exibe um carrossel interativo de produtos tech (Apple Watch Series 10, AirPods Max e Vision Pro) com animações suaves e transições cinematográficas.

---

## 🚀 Funcionalidades

- **Carrossel automático** — troca de produto a cada ~5 segundos
- **Navegação manual** — botões de seta (anterior / próximo)
- **Indicadores visuais** — dots e contador numérico sincronizados com o slide ativo
- **Animações de entrada** — imagem e texto deslizam ao mudar de produto
- **Efeito de pulso** — brilho central animado que acompanha o fundo
- **Hover na navegação** — sublinhado animado nos links do menu

## ▶️ Como Executar

Não é necessário instalar nada. Basta clonar o repositório e abrir o arquivo `index.html` no navegador:

```bash
git clone https://github.com/Marc0sbernardo/Dev-Club-Store.git
cd Dev-Club-Store
# Abra o index.html no seu navegador
```

Ou simplesmente arraste o arquivo `index.html` para uma aba do navegador.
